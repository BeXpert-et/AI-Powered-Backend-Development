# Course rules

The course combines recorded lessons, live workshops, practical assignments and student reviews.

- Students complete and submit weekly assignments, including weeks when they are not presenting.
- Submissions should be understandable, reproducible and accompanied by setup instructions.
- Students must be able to explain the code they submit, including AI-assisted code.
- Reviews focus on correctness, engineering reasoning, tests, security and maintainability.
- Feedback should be specific, respectful and constructive.
- Do not publish API keys, passwords or private user data in code, repositories or AI prompts.
- Final projects are student-selected and should have a realistic, testable scope.
