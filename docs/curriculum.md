# Revised curriculum

The 12-week program emphasizes backend engineering fundamentals before more advanced AI-assisted workflows. Recordings cover technical walkthroughs; workshops focus on reasoning, debugging, security, design decisions, and feedback.

| Week | Topic | Teaching emphasis |
|---|---|---|
| 1 | JavaScript, HTTP, Git | Functions, data handling, request/response basics |
| 2 | Async JavaScript and Node.js | Event loop, promises, errors, Node runtime |
| 3 | Express and REST | Endpoint contracts, middleware, separation of concerns |
| 4 | PostgreSQL and SQL | Relations, constraints, joins, transactions |
| 5 | TypeScript and Prisma | Type safety, schemas, migrations |
| 6 | Validation and authentication | Input boundaries, passwords, authentication concepts |
| 7 | Authorization and API security | Ownership checks, roles, unauthorized cases |
| 8 | Testing and documentation | Edge cases, OpenAPI, logs |
| 9 | Docker and deployment | Environment, CI, deployment and basic monitoring |
| 10 | LLM integration | Structured outputs, error handling, safe API integration |
| 11 | Background jobs and RAG | Queue/retry concepts, retrieval fundamentals |
| 12 | AI-assisted workflow and capstone | Review generated code, verify and defend technical decisions |

Advanced caching, distributed scaling, OAuth internals and full RAG pipelines are optional extensions, not required mastery.

**Capstone progression:** Project ideas in Week 8, MVP selection in Week 9, design in Week 10, core implementation in Week 11, and final presentation in Week 12. Students choose their project.
