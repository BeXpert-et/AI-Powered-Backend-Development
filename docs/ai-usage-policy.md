# AI usage policy

AI tools are part of the course, but foundational understanding comes first. Students do not need paid subscriptions.

| Weeks | AI use |
|---|---|
| 1–2 | Explanations and hints; core exercises completed independently |
| 3–5 | Debugging support and controlled scaffolding |
| 6–9 | AI pair programming with student review, testing and security verification |
| 10–12 | Supervised AI coding and planning workflows with verified changes |

Students remain responsible for all submitted code. Important engineering decisions — especially authentication, authorization, sensitive data handling and security — must be understood and independently verified.

Students should briefly describe how AI assisted them and how they checked the output. AI use must not replace the student's ability to explain their implementation during reviews.
